## Security research focus

- **Broken access control** — IDOR/BOLA, privilege boundary failures, and cross-user or cross-tenant access.
- **Authentication and session security** — account lifecycle, session handling, and authentication-flow weaknesses.
- **Business logic vulnerabilities** — workflow abuse, state-transition flaws, and unintended actions.
- **Web and API security** — authorization checks, request handling, and exposed functionality.
- **Source-code review** — tracing attacker-controlled input through security-sensitive code paths.

## How I work

`Scope → Map → Test → Validate → Report`

I verify that a target is in scope before testing, reproduce suspected issues under controlled conditions, compare behavior across the relevant roles or states, and document the security impact with clear evidence. I aim to submit concise reports that make the root cause and remediation path understandable.
